# Probe — KBD Constraints

Generated by `/kbd-init` on 2026-09-26 from `AGENTS.md` and `docs/DEVELOPMENT.md`.
`AGENTS.md` remains authoritative; this file makes its checkable rules machine-readable.

Command policy: every Cargo command runs with `CARGO_TARGET_DIR` unset
(`env -u CARGO_TARGET_DIR cargo …`, applied per command segment) and uses the
project `target/` directory. The inherited sandbox cache cannot compile
`gpui_macos` (Metal) or `aws-lc-sys`.

## Blocking Constraints (prevent archiving until resolved)

```yaml
constraints:
  - id: fmt-clean
    severity: blocking
    description: 'Formatting matches rustfmt'
    command: 'env -u CARGO_TARGET_DIR cargo fmt --check'

  - id: clippy-deny-warnings
    severity: blocking
    description: 'Clippy passes with warnings denied across all targets and features'
    command: 'env -u CARGO_TARGET_DIR cargo clippy --all-targets --all-features -- -D warnings'

  - id: tests-pass
    severity: blocking
    description: 'All tests pass across all targets and features'
    command: 'env -u CARGO_TARGET_DIR cargo test --all-targets --all-features'

  - id: deny-advisories
    severity: blocking
    description: 'No known security advisories in dependencies'
    command: 'env -u CARGO_TARGET_DIR cargo deny check advisories'

  - id: no-gpui-component-crate
    severity: blocking
    description: 'Use Longbridge gpui-base (import gpui_base), never the separate gpui-component crate as a dependency'
    check: "grep -nE '^\\s*gpui-component\\s*=' Cargo.toml crates/*/Cargo.toml"
    pass_when: 'no output'

  - id: domain-dependency-direction
    severity: blocking
    description: 'probe-core (domain) must not depend on GPUI, gpui-base, CLI libraries, YAML, HTTP-client types, or async/filesystem runtimes'
    check: "sed -n '/^\\[dependencies\\]/,/^\\[/p' crates/core/Cargo.toml | grep -Ei 'gpui|clap|yaml|reqwest|hyper|ureq|tokio'"
    pass_when: 'no output'

  - id: no-unsafe
    severity: blocking
    description: 'No unsafe code; never use unsafe to bypass ownership problems'
    note: 'Enforced by the compiler via [workspace.lints.rust] unsafe_code = "forbid"'

  - id: no-hardcoded-secrets
    severity: blocking
    description: 'No hardcoded API keys, tokens, or passwords in source'
    check: "grep -rnE '(api_key|secret|token|password)\\s*[:=]\\s*\"[A-Za-z0-9_\\-]{16,}\"' crates/ --include='*.rs'"
    note: 'Test fixtures with obvious placeholder values are acceptable; review matches manually'

  - id: opencollection-fixture-tests
    severity: blocking
    description: 'Every newly supported OpenCollection feature has fixture-based tests, including load → modify → save → reload where relevant'
    note: 'Manual review of the change diff'

  - id: atomic-safe-writes
    severity: blocking
    description: 'YAML writes are atomic, report failures, refuse to overwrite externally modified sources, and preserve unknown YAML where practical'
    note: 'Manual review of persistence changes'
```

## Warning Constraints (acknowledge before archiving)

## Workflow Triggers

```yaml
workflow_triggers:
  - event: on_iteration_complete
    action:
      type: command
      target: 'env -u CARGO_TARGET_DIR cargo check --workspace --all-targets --all-features'

  - event: on_change_complete
    action:
      type: command
      target: 'env -u CARGO_TARGET_DIR cargo fmt --check && env -u CARGO_TARGET_DIR cargo clippy --all-targets --all-features -- -D warnings && env -u CARGO_TARGET_DIR cargo test --all-targets --all-features && env -u CARGO_TARGET_DIR cargo deny check advisories'
```

The template's automatic `git add -A && git commit` trigger is intentionally
omitted: commits happen only on explicit request.
